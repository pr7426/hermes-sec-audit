# Security policy

## Supported versions

Only the latest commit on `main` is supported for security fixes.

## Reporting a vulnerability

Please do not open a public issue with credentials, source code, or an exploitable proof of concept. Use GitHub's private vulnerability reporting for this repository, or contact the maintainer privately with the affected endpoint, impact, and a minimal reproduction.

HermesSec is an automated pre-audit tool. Do not submit production secrets or confidential client code until the deployment's provider retention, access control, and tenant isolation have been reviewed.
